# غفار اے آئی (Ghaffar AI) — حصہ 1 اور 2

## اس ورژن میں کیا ہے
- Gemini سے بات چیت (اردو / انگلش)، لکھ کر یا 🎤 دبا کر بول کر
- جواب آواز میں سننا
- نماز کے وقت آواز میں پوچھنا: "کیا آپ نے نماز پڑھ لی؟" (نوٹیفکیشن میں "پڑھ لی" اور "10 منٹ بعد")
- نماز کا ہفتہ وار حساب (🕌 نماز بٹن)
- سونے کا موڈ: سورہ رحمٰن، 45 منٹ بعد آواز آہستہ ہو کر بند
- صبح کی تلاوت: آیت الکرسی اور سورہ یٰسین (مقررہ وقت پر خود چلتی ہے)
- قاری بدلنا + اپنا قاری ڈالنا
- Gemini API Key اور ماڈل سیٹنگ میں بدلنا

## ابھی شامل نہیں (اگلے حصے)
اسکرین پڑھنا، کیمرہ سے پڑھنا، میسج کا جواب، فون کو بول کر چلانا، یادداشت، ڈائری، حساب کتاب، لائیو ترجمہ، زبان سکھانا، کیپشن۔

## APK بنانے کا طریقہ (GitHub سے، فون پر ہی)

1. **github.com** پر لاگ ان کریں۔
2. اوپر "+" دبائیں، **New repository** چنیں، نام `GhaffarAI` رکھیں، **Create repository** دبائیں۔
3. نئے repository میں **uploading an existing file** کا لنک دبائیں۔
4. اس ZIP کو فون میں **Extract** کر لیں، اور اندر کی **سب فائلیں اور فولڈر** (app، .github، build.gradle.kts وغیرہ) اپلوڈ کریں۔
   - اگر `.github` فولڈر چھپا ہو تو فائل مینیجر میں "Show hidden files" آن کریں۔ یہ فولڈر ضروری ہے۔
   - اگر فون سے فولڈر اپلوڈ نہ ہو، تو ڈیسک ٹاپ سائٹ (Chrome → "Desktop site") کھول کر کریں۔
5. نیچے **Commit changes** دبائیں۔
6. اوپر **Actions** ٹیب کھولیں۔ "Build APK" چل رہا ہوگا (3 سے 8 منٹ)۔
7. ہرا ✅ آ جائے تو اس پر دبائیں، نیچے **Artifacts** میں **GhaffarAI-apk** ڈاؤن لوڈ کریں۔
8. ZIP کھولیں، `app-debug.apk` انسٹال کریں (فون "نامعلوم ذرائع سے انسٹال" کی اجازت مانگے تو دے دیں)۔
9. اگر ❌ لال نشان آئے تو اس پر دبا کر آخری ایرر کی لائنیں مجھے بھیج دیں، میں ٹھیک کر دوں گا۔

## پہلی بار ایپ میں
1. ⚙️ سیٹنگ کھولیں، **Gemini API Key** ڈالیں، اپنا شہر اور ملک انگلش میں لکھیں۔
2. نوٹیفکیشن اور "Alarms & reminders" کی اجازت دیں۔
3. سیٹنگ میں **"بیٹری پابندی ہٹائیں"** دبائیں، تاکہ ایپ بند ہونے پر بھی وقت پر چلے۔
4. اردو آواز کے لیے: فون کی Settings → Text-to-speech → Google → Urdu آواز ڈاؤن لوڈ کریں۔
5. بعض فونز (Xiaomi، Oppo، Vivo، Infinix) میں ایپ کی سیٹنگ میں "Autostart" بھی آن کرنا پڑتا ہے۔
